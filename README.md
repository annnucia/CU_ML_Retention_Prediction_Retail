# CU_ML_Retention_Prediction_Retail

Мы предсказываем: Сделает ли клиент повторную покупку в следующие 90 дней?

Датасет Online Retail II содержит транзакции интернет-магазина из Великобритании за период с 01.12.2009 по 09.12.2011. Компания в основном продает уникальные подарочные наборы на все случаи жизни. Многие клиенты фирмы — оптовики.

## О проекте

В проекте решается задача бинарной классификации. Нам нужно определить, вернется ли клиент за повторной покупкой в течение следующих 90 дней.

Данные были преобразованы из уровня транзакций в уровень клиентов. Для каждого клиента рассчитали агрегированные признаки: количество заказов, выручка, давность последней покупки, частота покупок, возвраты, разнообразие товаров и другие поведенческие характеристики.

## Метод

Основной использованный метод — **Random Forest Classifier**.

Также для сравнения мы использовали **Logistic Regression** как baseline-модель. Качество моделей оценивалось по метрике **ROC-AUC**, так как задача связана с предсказанием вероятности возврата клиента.

Лучший результат получился около **ROC-AUC = 0.80**.

## Дополнительно

В проекте также использовались:

- обработка выбросов;
- генерация новых признаков;
- отбор признаков;
- поиск аномалий;
- интерпретация модели через SHAP и LIME.

## Вывод

Модель показывает, что поведение клиента в прошлом хорошо помогает предсказывать вероятность повторной покупки. Наиболее важными признаками оказались давность последней покупки, частота заказов, выручка и активность клиента.
